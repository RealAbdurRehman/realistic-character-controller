# Physics Based Character Controller

A physics based character controller built with Three.js and Rapier, focused on realistic movement, procedural animations, and ragdolls.

## Tech

- Rapier
- Three.js
- TypeScript

## Goals

- [x] Basic Movement
- [x] Basic Camera
- [ ] Animations
- [ ] Polished Movement
- [ ] Polished Camera
- [ ] Physics based animations
